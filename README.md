# Untitled Platformer Game - README

Untitled Platformer Game is a game I created to give myself an introduction to coding and game development on real coding platforms outside of what I was taught at school.

I was not able to complete the development of the game, as I was very busy during this time, but participating in Stardance gave an insight into how real game development works. 
Becoming familiar with Hack Club and its events has inspired me to create my own independent projects in the future.
